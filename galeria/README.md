# Galería de casas

La app lee `lista.json` desde aquí y muestra las casas nuevas con 🌐.

Para agregar una casa:
1. En la app, usa 💾 Guardar proyecto para bajar el archivo `.json`.
2. Súbelo a esta carpeta con un nombre corto, sin espacios (por ejemplo `casa-lago.json`), junto con una imagen `.jpg` de 300 × 200 píxeles.
3. Agrega una entrada en `lista.json` con estos campos: `id`, `n` (nombre), `d` (descripción), `A` (m²), `dorm`, `pisos`, `img` y `file`.
